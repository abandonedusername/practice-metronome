Install & offline use

This app can work offline. To install it like a regular app, put the included app files on a secure HTTPS website, open that address, and use “Add to Home Screen” (iPhone/iPad) or “Install app” (Android/Chrome). A downloaded HTML file can also open in a browser, although saving may depend on the browser's file permissions.
